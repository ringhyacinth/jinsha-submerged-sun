## 体验方式

电脑端使用 `WASD` 游动，`Space / Shift` 上浮和下潜，鼠标观察视线，靠近文物后按 `1` 进行交互。

手机端使用右下角摇杆移动，右侧按钮上浮 / 下潜，左侧“交流”按钮进行文物交互，在画面空白处拖动转向。页面会尝试进入沉浸式全屏，并根据浏览器可视视口和安全区调整控件位置。

## 发布内容

当前版本包含动态水面、水下折射与吸收、海草、礁石、鱼群、文物低语、点云消散、破水效果和场景音乐。景深默认关闭，以便移动端和普通电脑优先保持稳定帧率。
